# Comparison of extraction A and extraction B

This record compares the specification package (A: `spec/` and `fixture/fixture.md`) with the second extraction (B: `records/extraction-second/`). The reference build (`web/src/`) and `fixture/service.json` decide each disagreement. The code was read. No browser was run.

## Summary

B was divided into 138 units: rules, faces, table rows, notice texts, timers and data rules (51 in `app.md`, 51 in `board.md`, 36 in `card.md`).

| Class | Meaning | Count |
| --- | --- | --- |
| 1 | In both, and they agree | 114 units of B agree fully |
| 2 | In B, missing from A | 15 items |
| 3 | A and B contradict | 7 items (the build supports B in 5 and A in 2) |
| 4 | In A, missing from B (deliberate decisions only) | 13 items |
| 5 | B is wrong or imprecise against the build | 8 items |

The 24 other units of B agree with A in their main statement and hold one or more of the items below.

Ranks (r1, r2) and emphasis (P, N, Q) are different in almost every face. The build drops no content, so the code cannot decide them. They are not counted.

The last section lists four points where the build disagrees with A and B does not help. They are not counted in the classes.
